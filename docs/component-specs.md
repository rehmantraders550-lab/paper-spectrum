# Paper Spectrum — Component Specifications

## 1. Masthead
- Height target: ~64px desktop; content-driven mobile.
- No large logo lockup.
- Brand left, minimal navigation right.
- 1px rule may define lower edge.
- Navigation uses 13px sans, uppercase or restrained title case.
- Mobile menu must not introduce animated full-screen spectacle; simple disclosure is preferred.

## 2. Editorial Hero
- One dominant idea: title OR image, never five competing objects.
- Display serif: 42–60px.
- Large quiet space above/below.
- Preferred image treatments: centered object, asymmetric editorial image, or full-width visual.
- CTAs remain text links or minimal 1px treatments.

## 3. Feature Split
Approved geometry: 5/7, 7/5, 4/8, 8/4.
- Keep both sides aligned to the same 12-column grid.
- Text never floats arbitrarily over imagery unless the image has intentional negative space.
- Mobile stacks in semantic reading order.

## 4. Article / Project Grid
- 4 columns desktop as default Paper Spectrum interpretation.
- 2 tablet.
- 1 mobile.
- 20px horizontal gap.
- 60px vertical gap.
- Image first, then 20px gap, then metadata/title/deck.
- No surrounding card background, border, radius, or shadow.

## 5. Indexed Register
For categories, materials, archives, or process steps.
- Continuous vertical structure; do not render each row as a card.
- 1px rules define rhythm.
- Index / title / optional note.
- Persistent active state only if the content truly changes.
- Static registers must not pretend to be interactive.

## 6. Full-Bleed Image Passage
- Used sparingly as a chapter boundary.
- 100vw image or controlled page-max image.
- No radius.
- Text overlay only when image composition provides safe negative space.
- This is the primary "image bridge" primitive; do not repeat between every section.

## 7. Long-Form Reading Column
- Max 680px.
- 15px serif body at 1.5 line height.
- Lead paragraph may use 20px / 1.33.
- Paragraph gaps: 20–24px.
- Major subhead transition: 60–80px.

## 8. Curatorial Pause
- 120–200px vertical breathing room.
- May contain one short statement, folio mark, or nothing beyond a rule.
- No boxed container.
- Purpose: reset visual density before the next chapter.

## 9. Newsletter / Input
- No rounded field shell by default.
- Bottom or full 1px rule.
- Strong label semantics.
- Focus changes rule contrast, not glow/shadow.

## 10. Footer Register
- Dense relative to page body but still rule-led.
- Site index, legal, contact, newsletter.
- Can reverse to ink background, white type.
- Keep hierarchy typographic, not card-based.
