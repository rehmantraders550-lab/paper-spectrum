# Paper Spectrum — QA Gates

A page is not complete until it passes all gates.

## Geometry Gate
- [ ] Outer content does not exceed 1400px unless intentionally full-bleed.
- [ ] Main working grid stays within 1280px.
- [ ] Desktop uses coherent 12-column alignment.
- [ ] Standard gutter is 20px where grid columns interact.
- [ ] Reading copy stays ≤680px.
- [ ] Mobile has ≥24px page gutter.

## Rhythm Gate
- [ ] Spacing values come from the approved scale.
- [ ] No arbitrary 37px / 53px / 91px one-off gaps without documented optical reason.
- [ ] Major content changes receive 80–120px separation.
- [ ] At least one genuine curatorial pause appears on long pages.
- [ ] Two dense/interactive sections do not collide without a release zone.

## Typography Gate
- [ ] Editorial voice is serif.
- [ ] UI/meta is sans.
- [ ] Primary headings remain weight 400.
- [ ] Tracking tightens as display size increases.
- [ ] Body line-height remains ~1.5.
- [ ] No body line becomes excessively long.

## Surface Gate
- [ ] Cards do not look like dashboard cards.
- [ ] Default radius is 0.
- [ ] Rules are 1px.
- [ ] No decorative shadows.
- [ ] No gradients/glass effects.
- [ ] Tonal accent appears as a large field, not tiny badges.

## Motion Gate
- [ ] Micro interactions ~220ms.
- [ ] Small transitions ~400ms.
- [ ] Editorial reveals ~800ms.
- [ ] Easing uses cubic-bezier(.25,1,.5,1) or documented equivalent.
- [ ] No bounce/spring.
- [ ] No entrance drift over 8–10px.
- [ ] No blur-based reveals.
- [ ] Reduced-motion produces a complete, readable page.

## Interaction Gate
- [ ] Hover never gates information.
- [ ] No autoplay carousel.
- [ ] No scroll hijacking.
- [ ] Keyboard focus is visible.
- [ ] Stateful components expose correct ARIA state.
- [ ] Static rows do not pretend to be controls.

## Editorial Gate
- [ ] One primary idea dominates each viewport.
- [ ] Photography carries visual weight.
- [ ] Interface chrome remains subordinate.
- [ ] Adjacent sections do not repeat identical composition.
- [ ] Page reads like a sequence of spreads, not stacked widgets.

## Authenticity Gate
- [ ] Paper Spectrum identity is visible independently of the reference model.
- [ ] No Kinfolk logos, copy, imagery, or proprietary fonts are used.
- [ ] Spectrum Wash and Newsreader/Inter pairing make the system distinct.
